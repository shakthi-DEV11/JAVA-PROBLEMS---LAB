## 📌 About the Project

**Java Problems Lab** is a hands-on programming repository focused on developing strong Core Java fundamentals and improving algorithmic thinking through practical coding exercises.

The project organizes Java problems into separate packages and provides a console-based main menu for navigating between problem categories.

Rather than treating programming as memorizing syntax, the goal is to practice implementing algorithms, understanding program flow, and gradually improving code quality.

### 🎯 Project Objectives

- Strengthen Core Java fundamentals.
- Improve logical reasoning and algorithmic problem-solving.
- Practice loops, conditionals, methods, classes, and packages.
- Learn array and string manipulation techniques.
- Understand number theory and mathematical algorithms.
- Build a consistent coding practice portfolio on GitHub.

## ⚙️ Getting Started

### Prerequisites

- A compatible Java Development Kit (JDK).
- IntelliJ IDEA or another Java-compatible IDE.
- Git, if you want to clone the repository.

Verify your Java installation:

```bash
java -version
javac -version
```

### 1. Clone the Repository

```bash
git clone https://github.com/shakthi-DEV11/JAVA-PROBLEMS---LAB.git
```

### 2. Open the Project

Open the cloned `JAVA-PROBLEMS---LAB` folder in IntelliJ IDEA and configure the project SDK to match your installed JDK.

### 3. Compile and Run

From the project root, use the following commands.

**Windows PowerShell**

```powershell
New-Item -ItemType Directory -Force out | Out-Null

$files = Get-ChildItem src -Recurse -Filter *.java |
    ForEach-Object { $_.FullName }

javac -d out $files

if ($LASTEXITCODE -eq 0) {
    java -cp out Main
}
```

**Linux / macOS**

```bash
mkdir -p out
javac -d out $(find src -name "*.java") && java -cp out Main
```

These commands compile the Java source files into `out` and launch the `Main` class if compilation succeeds.
